xTc Personal AI System

One assistant, on my machine, on my terms.

Concept

A personal AI system that acts as one central intelligence: coder, designer, researcher and email and productivity assistant, with its own animated desktop interface and voice, and later a mobile companion. It runs on my own laptop first and is built so that I stay in control of what it learns and what it can do.

Type
Personal AI system
My role
Product owner and creative director

Why build it

Paid AI subscriptions add up, and each tool knows only a slice of my work. I want one system that knows my projects, runs locally where it can, and is not tied to a single provider.

Principles

  • Runs locally on my laptop first, using open weight and local models where practical
  • Modular, so any model or provider can be swapped
  • Learns only from sources I explicitly authorise
  • Every memory can be inspected, edited and deleted, and follows my approval rules
  • It can never expand its own permissions

What it should do

  • Write and review code
  • Help with design work
  • Research
  • Handle email and day to day productivity
  • Talk by voice through its own animated desktop interface
  • Later, a mobile companion
  • Host the xTc Personal AI Studio for photo and video editing

How it will be built

  1. Visual identity

    How the system looks and feels before anything else.

  2. Interface architecture

    The desktop command centre and how voice, chat and tools fit together.

  3. Core system design

    Models, memory, permissions and how modules plug in.

  4. Milestones

    Then built milestone by milestone, not as a rushed prototype.
